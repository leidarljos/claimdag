How-to guides
=============

These are the tasks after the :doc:`tutorial <getting-started>`. Each one
is a single goal. The :doc:`concepts <concepts>` page defines the words,
and the :doc:`reference <reference>` is every flag.

-  :doc:`Point at a graph <howto-dir>`: ``--dir``, ``CLAIMDAG_DIR``, and the defaults ``where`` prints.
-  :doc:`Take the next node <howto-take>`: ``ready``, ``ready --balanced``, and ``claim-next``.
-  :doc:`Fence a completion <howto-lease>`: ``renew``, ``release``, ``reclaim``, and ``complete --gen``.
-  :doc:`Archive finished work <howto-archive>`: ``archive``, ``list --terminal``, ``list --all``.
-  :doc:`Drive the pane <howto-pane>`: keys, ``--dump``, ``CLAIMDAG_ACTOR``, ``CLAIMDAG_HANDLES``.
-  :doc:`Serve the graph <howto-mcp>`: the tools and the two prompts.

A tracker id is mapped by the seat, documented at https://leidarljos.github.io.
On its own, claimdag takes 32-hex ids only.
