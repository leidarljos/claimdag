Tutorials
=========

The tutorial is one path. It uses a scratch directory, two nodes, and one
actor. By the end a second claim has been refused, a lease has been
renewed, and finishing the parent has made the child ready.

Put ``claimdag`` on ``PATH`` from the :doc:`installation <install>` page,
then follow :doc:`Getting started <getting-started>` from the first
command. The page is the whole lesson. The :doc:`how-to guides <howto>`
are the tasks that come after it, and the :doc:`concepts <concepts>` page
names the edges the lesson creates.
